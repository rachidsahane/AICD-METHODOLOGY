# Changelog

All notable changes to AICD: Artificial Intelligence Centered Development are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

*The document records months only, not days, so every date below is given to the month.*

## [Unreleased]

## [0.3] - 2026-09

External critique reviewed and adopted where warranted.

### Added

- New Part VIII, extensions and profiles:
  - Simulation personas and finding quality.
  - Agent instruction design.
  - Design in the loop.
  - The reference organizational repository.
  - Profiles for mobile clients.
  - Disconnected operation.
  - Regulated domains and the single operator.
  - Lessons from the first application recorded as rules.
- New rule in section 14: a gate is installed only when it has been seen to fail on a planted defect.

### Changed

- Section 7: three-layer review with deterministic checks and an adversarial checklist.
- Section 8: sanitization barrier between telemetry and operational memory.
- Section 12: conflict handling at scale with declared scope and a lock table.
- Section 15: proposed criteria and QA run budgets.
- Section 23: foundation set and phase set replacing the all-upfront specification.
- Open questions rewritten.

## [0.2] - 2026-09

### Added

- New Part VI, applying AICD:
  - Starting a new product:
    - Gates G0 to G7.
    - Inherited golden rules.
    - Specification set.
    - Tag promotion replacing the three-branch model.
  - Migrating an existing product:
    - Phases M0 to M5.
    - Access attribution at migration time.
    - The fourteen as-built documents.
    - Verification baseline.
    - Progressive autonomy.
    - Exit checklist.
    - Special cases.
- New Part VII, deep dives:
  - Memory service implementation.
  - Multi-product operation.
  - Security and compliance in depth.
  - Fleet dashboard.
  - Extension process and versioning.
  - Calibration procedures.

### Changed

- Section 15 revised: continuous test environment becomes event-driven, exhaustive runs on significant modifications.
- Section 21 revised: no absolute cost baseline, performance-relative thresholds and calibration sets.
- Open questions rewritten.
- Glossary extended.
